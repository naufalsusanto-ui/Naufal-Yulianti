# Undangan Pernikahan Naufal & Yulianti — Luxury Blush Floral

Template website statis HTML/CSS/JavaScript untuk GitHub Pages. Bahasa Indonesia, gaya blush pink mewah, ornamen floral berlapis, aksen rose-gold, bingkai foto melengkung, animasi kelopak dan reveal saat scroll.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser untuk pratinjau (beberapa fitur memerlukan koneksi internet untuk Google Fonts).
3. Untuk GitHub Pages, unggah isi folder ini ke root repositori. Pastikan `index.html` berada langsung di root serta folder `assets` ikut diunggah.

## Aset
- `assets/images/cover.jpg`: foto sampul
- `assets/images/groom.jpg`, `bride.jpg`: foto profil
- `assets/images/gallery-1.jpg` sampai `gallery-4.jpg`: galeri
- `assets/images/floral-corner.svg`: ornamen floral mawar, daun, dan aksen emas
- `assets/images/silk-ribbon.svg`: aset pita dekoratif tambahan

## Data yang perlu dicek
Data mempelai dan acara telah diisi berdasarkan undangan PDF. Informasi rekening dan alamat pengiriman hadiah masih berupa placeholder dan harus diisi sendiri. Form RSVP adalah pratinjau lokal dan belum terhubung ke Google Sheets.
