# Undangan Pernikahan Naufal & Yulianti — Luxury Blush Floral (Revisi)

Template website statis HTML/CSS/JavaScript, Bahasa Indonesia, floral blush pink mewah, aksen rose-gold, foto pasangan, animasi ornamen dan animasi saat scroll.

## Perbaikan pada revisi ini
- File `index.html` berada langsung di root ZIP supaya mudah diunggah ke root repositori.
- Semua foto yang dirujuk HTML disertakan dalam `assets/images/` dan dioptimalkan agar lebih ringan.
- Teks nama dan tanggal awal sudah sesuai data: Naufal Zain Susanto & Yulianti Effendi, Minggu 27 Desember 2026.
- Ornamen floral SVG disertakan; pastikan folder `assets` diunggah bersama `index.html`.
- CSS mendukung tampilan responsif dan pengaturan reduce motion.

## Cara pratinjau di Windows
1. Ekstrak ZIP.
2. Klik dua kali `index.html` untuk membukanya di Chrome.
3. Untuk memeriksa semua foto dan ornamen, jangan memindahkan `index.html` terpisah dari folder `assets`.

## Cara unggah ke GitHub Pages
Unggah `index.html` dan folder `assets` ke root repositori (halaman utama repo), bukan folder pembungkus. Pastikan path menjadi `assets/images/cover.jpg`, `assets/images/groom.jpg`, `assets/images/bride.jpg`, `assets/images/gallery-1.jpg` sampai `gallery-4.jpg`, `assets/images/floral-corner.svg`, dan `assets/images/silk-ribbon.svg`.

## Catatan fitur
- Form RSVP/ucapan pada template ini belum menyimpan data ke server atau Google Sheets.
- Musik latar tidak disertakan; jika ingin musik, tambahkan `assets/audio/wedding-music.mp3`.
- Data rekening/alamat hadiah masih placeholder dan perlu diganti sebelum undangan dibagikan.
